# MAVO basemap

OpenFreeMap vector data, rendered with MapLibre GL JS 5.6.2 and the Leaflet bridge 0.0.22. Local style derives from OpenMapTiles Positron, recolored for light streets, pale blue water and soft green parks. Original source: https://tiles.openfreemap.org/styles/positron . Data requests need no API key. Provider information: https://openfreemap.org/ . This is a visual approximation, not CARTO Voyager.

The bundled Mapbox RTL text plugin 0.3.0 supports Hebrew with MapLibre 5. Licenses are included alongside these files. Leaflet owns all markers, filters, scrolling and gestures; one touch scrolls the page, two touches translate/zoom the map. Physical phone QA is still needed; Chromium touch emulation passed.
